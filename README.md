# BFME II Permanent Zoom Fix

## Install

1. Put `zoomfix.ini` in:
   `C:\Users\user\AppData\Roaming\My Battle for Middle-earth(tm) II Files`
2. Put `dinput8.dll` in:
   `C:\Program Files (x86)\Electronic Arts\The Battle for Middle-earth (tm) II`

## Remove the fix

Delete `dinput8.dll` from the game folder.
